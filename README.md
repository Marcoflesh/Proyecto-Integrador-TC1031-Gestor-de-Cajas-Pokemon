# Proyecto-Integrador-TC1031-Gestor-de-Cajas-Pokemon
Este es un proyecto en el cual el usuario tendrá su equipo Pokemon y podrá almacenarlo dentro de un sistema de cajas similar al juego de las consolas de Nintendo

# Nota
Si se está compilando en Windows, favor de quitar estos comentarios para que la consola pueda mostrar los acentos en el programa.

```
#include <Windows.h>
SetConsoleOutputCP(CP_UTF8);
SetConsoleCP(CP_UTF8);
setlocale(LC_NUMERIC, "C");
```

## Compilar
primero ingresar esta línea a la terminal para poder compilar el código
`
g++ main.cpp PC.cpp Pokemon.cpp User.cpp -o main
`
después ingresar esto en terminal para poder ejecutar el programa
`
./main
`
